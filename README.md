# Kikune

**An Android doujin voice library and audio player.**

Kikune is a personal Android app for organizing and listening to locally stored doujin voice works and ASMR.

> **Project status:** Early development. The application is being adapted from [AniZen](https://github.com/salmanbappi/AniZen). Features and architecture are subject to change.

## Goals

- Organize audio works into a personal library.
- Treat each work as a collection of tracks.
- Support local audio playback and remember playback progress.
- Provide background playback and media controls.
- Keep useful library, organization, theming, and backup capabilities from the upstream project where appropriate.

## Scope

The initial focus is local audio files. Online catalogs, DLsite integration, scraping, and external source extensions are intentionally out of scope for now.

## Upstream

Kikune is based on [AniZen](https://github.com/salmanbappi/AniZen), an Android media application built with Kotlin and Jetpack Compose.
